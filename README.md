# Технология доступа к базам данных ADO.NET

Учебный репозиторий по дисциплине **«Технология доступа к базам данных ADO.NET»**.

Здесь собраны теоретические материалы, практические и домашние работы по разработке приложений на C# с использованием ADO.NET.

## 🛠️ Стек технологий

- **Язык программирования:** C#
- **Платформа:** .NET 8
- **Фреймворк:** ASP.NET Core MVC
- **База данных:** PostgreSQL
- **Провайдер доступа к БД:** Npgsql
- **Контейнеризация:** Docker, Docker Compose
- **Среда разработки:** Visual Studio
