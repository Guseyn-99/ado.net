# Работы по дисциплине "Технология доступа к базам данных ADO.NET"

В данном репозитории хранятся лабораторные работы по предмету ADO.NET.

## 🛠 Стек технологий
*   **Язык:** C# (.NET 8)
*   **Фреймворк:** ASP.NET Core MVC
*   **База данных:** PostgreSQL 16
*   **Провайдер БД:** Npgsql (ADO.NET)
*   **Контейнеризация:** Docker, Docker Compose

## 🚀 Как запустить проект (Лабораторная работа: Магазин)
1. Установите Docker Desktop.
2. Откройте терминал в папке с проектом.
3. Выполните команду:
   ```bash
   docker compose up --build -d
