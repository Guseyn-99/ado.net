## 📁 Структура домашних заданий

Каждая работа находится в отдельной папке и содержит исходный код и описание.

**Работа №1 — Комплексные задачи ADO.NET**

- `src/` — исходный код проекта.
- `README.md` — описание выполненной работы.
- Word-документ — материалы и результаты выполнения.

**Работа №2 — 10 задач по ADO.NET**

- `Task_01/` – `Task_10/` — десять отдельных заданий на C#.
- `Program.cs` — исходный код каждого задания.
- `.csproj` — файлы проектов .NET.
- `setup.sql` — SQL-скрипт подготовки базы данных.
- `README.md` — описание работы и инструкция по запуску.

## Цель

Закрепление навыков работы с реляционными базами данных с использованием ADO.NET, выполнения SQL-запросов, управления транзакциями и обработки данных в C#.
