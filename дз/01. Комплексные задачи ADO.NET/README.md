# Домашняя работа № 1 — Комплексные задачи по ADO.NET (Npgsql)

## Цель
Отработать взаимодействие консольного приложения C# с PostgreSQL через ADO.NET и Npgsql.

## Технологии
- C# / .NET 8
- PostgreSQL
- Npgsql 10.0.3

## Выполненные задания

| № | Тема | Реализация |
|---|---|---|
| 1 | Пагинация | `LIMIT`, `OFFSET`, отмена по таймауту |
| 2 | Удаление | `ExecuteNonQuery`, проверка количества строк |
| 3 | Статистика | `COUNT`, `SUM`, `AVG` |
| 4 | Оформление заказа | Транзакция, `FOR UPDATE`, `Commit` / `Rollback` |
| 5 | Массовое обновление | Обновление остатков с откатом при ошибке |
| 6 | Чтение данных | `NpgsqlDataReader` |
| 7 | DataTable | `NpgsqlDataAdapter` |
| 8 | Асинхронное чтение | `OpenAsync`, `ReadAsync` |
| 9 | Обработка ошибок | `PostgresException`, SQLSTATE `23505` |
| 10 | Пул соединений | 20 параллельных запросов, лимит пула 5 |

## Запуск

1. Установить .NET 8 SDK и PostgreSQL; подготовить базу `npgsql_tasks` и таблицы `employees`, `parts`, `orders`.
2. В PowerShell задать строку подключения **локально**, не публикуя пароль:

   ```powershell
   $env:ADO_NET_CONNECTION_STRING = 'Host=localhost;Port=5432;Database=npgsql_tasks;Username=postgres;Password=ВАШ_ПАРОЛЬ;Maximum Pool Size=5;Minimum Pool Size=1'
   ```

3. Перейти в `src` и запустить:

   ```powershell
   dotnet restore
   dotnet run
   ```

> **Внимание:** программа изменяет данные БД (удаляет запчасть, создаёт заказ и меняет остатки). Запускайте на учебной базе. Задание 9 проверяет обработку дублирующегося артикула `BRK-001`.

## Структура

- `src/Program.cs` — реализация 10 заданий.
- `src/NpgsqlTasks.csproj` — зависимости и настройки проекта.

## Результат
Реализованы 10 заданий. В исходной версии задания 2–7 и 9 выполняются синхронно, задания 1, 8 и 10 используют асинхронные операции. Скриншоты и результаты из отчёта относятся к исходному запуску; после изменений требуется повторная проверка.
