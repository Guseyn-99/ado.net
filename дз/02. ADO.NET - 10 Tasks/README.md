## Запуск

Для выполнения потребуется .NET 8 SDK, установленный PostgreSQL и подготовленные таблицы из `setup.sql`. **Docker не требуется.**

Настройте подключение в терминале PowerShell (замените пароль своим):

```powershell
$env:PG_CONNECTION_STRING = 'Host=localhost;Port=5432;Database=npgsql_tasks;Username=postgres;Password=ВАШ_ПАРОЛЬ;Maximum Pool Size=5;Timeout=5'
```

Запуск отдельного задания из этой папки:

```powershell
dotnet run --project Task_01
```

Аналогично `Task_02`, ... `Task_10`. Задание 2 импортирует **50 000** строк, задания 3, 8 и 10 меняют данные в базе.
